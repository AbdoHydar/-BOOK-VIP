# Bankak Native Flutter - Splash + Login + Home

هذه نسخة Flutter Native أولى تحتوي على:

- Splash Native بالفيديو `splash.mp4`
- Login مطابق بصرياً باستخدام خلفية `login.png` وحقول Flutter حقيقية فوقها
- Home Native بنفس ترتيب وأيقونات صفحة `home.html`
- GitHub Actions لبناء APK
